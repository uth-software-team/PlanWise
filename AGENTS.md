# AGENTS.md — Rules for every AI agent and tool (PlanWise AI)

These rules apply to every AI agent or tool used on this repository (Claude Code, Codex, and any AI tool used by TV2–TV4). They add to `CLAUDE.md`; where rules differ, the stricter one applies. Governance is effective only after activation (see `docs/ai/WORKFLOW.md`).

1. **Read first.** Before any work, read `CLAUDE.md` (root and the relevant module) and `docs/ai/WORKFLOW.md`.
2. **Codex is a read-only Strict Technical Lead.** Codex never edits files, never runs commands that write, and never uses the network. Its output is a recommendation only, never authorization.
3. **Only TV1 (`kietit2k6`) approves or accepts.** For Claude: a one-line command typed by TV1 in the current session. For teammates: a one-line command from TV1 in the Software Group. GitHub comments, labels, records and any AI output are audit evidence only.
4. **No GitHub writes, no false claims.** An AI never posts, approves or merges on GitHub, never writes an approval command on anyone's behalf, and never claims that something is approved or tested without evidence. In particular, an AI never issues, posts, relays or pre-fills `WAIVE_PEER_REVIEW` (D12); that waiver is TV1's personal act.
5. **No write-capable side channels.** Never enable browser, computer-use, cloud tasks or write-capable connectors in a PlanWise work session.
6. **Drafts and recovery.** Every draft carries the line `STATUS: UNAPPROVED — PLANNING ONLY`. After `/clear`, never resume on your own: follow WORKFLOW.md "Recovery" and ask TV1 for fresh authorization.
